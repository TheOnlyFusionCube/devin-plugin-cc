# fusion (skill)

Fusion lead/sidekick workflow as a portable agent skill: a frontier model (GPT 6 Astra in Codex, Claude Opus 5.5 in Claude Code) keeps intent, planning, and final review while Devin handles bounded mechanical or test-heavy work.

Invoke with `$fusion <task>` in Codex, or install alongside the main plugin. See the [repository README](https://github.com/TheOnlyFusionCube/devin-plugin-cc) for details.
